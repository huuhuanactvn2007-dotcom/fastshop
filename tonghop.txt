Phần 1:
Hệ thống của em gồm server Ubuntu, service db và service be. Các port được phân bổ bao gồm port cho nginx, be, db. Có 1 domain huan20.io.vn và 2 subdomain admin và api. Đã tích hợp cloudflare và trỏ vào tên miền huan20.io.vn
Phần 2:
User khi gõ domain, request sẽ được gửi về máy chủ Cloudflare trước tiên và chuyển tiếp request về IP Server. Nginx sẽ tiếp nhận request này ở port 80/443 và đọc cấu hình xem để chuyển vào các service tương ứng. Request vào FE trả về giao diện, request về BE sẽ xử lí logic. Nếu cần dữ liệu sẽ gọi DB
Phần 3:
Em vẫn đang deploy bằng tay, có file checklist deploy nhưng chưa tự động hóa quy trình này, và phần verify rất yếu.
Phần 4: Rủi ro kĩ thuật
- Deploy tay dễ quên bước
- Lộ origin IP
- Thiếu rollback
- nginx config sai
- Thiếu monitoring log
Phần 5: 3 việc ưu tiên làm
- Tự động hóa quy trình deploy
- Đóng các port cần bảo mật
- Tích hợp các hệ thống monitor cơ bản
