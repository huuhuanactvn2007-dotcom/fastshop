1. Em đã dùng Dockerfile như thế nào
 Sử dụng Dockerfile để đóng gói source Java Spring Boot thành 1 image hoàn chỉnh.
 Sử dụng kỹ thuật Dockerfile Multi-stage Build với 2 giai đoạn:
  -Giai đoạn 1: builder: Sử dụng image JDK/Maven để biên dịch toàn bộ source sang file .jar
  -Giai đoạn 2: runtime: Sử dụng image JRE để copy file .jar sang.
2. Em đã dùng Docker Compose như thế nào
 Sử dụng file docker-compose.yml để quản lý toàn bộ hệ thống chạy đồng thời chỉ với 1 câu lệnh
 - Cấu hình Docker Network nội bộ
 - Khai báo SQL Server
 - Khai báo Service Application
 - Quản lý thứ tự khởi động
3. Nếu hệ thống chưa chạy được ngay từ đầu, lỗi nằm ở đâu?
 - Viết sai file Dockerfile 
 - Lỗi logic ứng dụng, frontend khi đóng gói thành image bị lỗi thừa dấu / dẫn đến Linux hiểu lầm đi tìm thư mục ở gốc hệ thống thay vì trong project
4. 5 lỗi kỹ thuật em có thể gặp khi Docker hóa source code này là gì?
   - 1. Lỗi phân biệt chữ hoa và thường
   - 2. Lỗi Cache lớp: khi sửa giao diện hoặc dockerfile mà build lại thì quên dùng --no-cache khiến Docker có thể giữ nguyên cache cũ
   - 3. Lỗi sai phiên bản
   - 4. Lỗi dùng localhost trong Docker: mỗi container app, db hoạt động như những máy ảo độc lập, có IP riêng. Nên dùng localhost thì khi app gọi db sẽ bị lỗi do nó tìm ngay trong container của nó.
   - 5. Lỗi sai định dạng: ta bị thừa hoặc thiếu những khoảng trắng, dẫn đến Docker không biên dịch được file và báo lỗi.
5. Nếu mở rộng tiếp, em sẽ thêm database / nginx / env / volume ra sao?
 - Thêm nginx làm reverse proxy: Đóng cổng 8000 lại và cấu hình nginx đón request qua port 80/443 sau đó mới điều hướng về port 8000
 - Thêm docker volume cho database giúp dữ liệu được gắn vào ổ cứng máy thật, đảm bảo các thao tác với container không làm mất dữ liệu - đã làm
 - Thêm file .env riêng để lưu trữ tài khoản, pass.
